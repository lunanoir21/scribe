Features

Built to disappear.

Your text stays put

No re-drawn copy, no boxes over the content. Dragging draws a soft highlight per line, exactly like selecting real text.

Fast on every core

The selection is cut into strips at blank rows and each strip is read by its own Tesseract. A full 1080p screen takes about a second.

One window

Picker, scan animation and result share one layer-shell window, so nothing flickers between steps.

Dark themes just work

Light text on a dark background is inverted before reading. Small selections are read at 2x, shaky reads are retried once.

Languages from settings

A gear opens settings. For a missing language you pick: download it straight into your home folder, or install it with your package manager.

Reversible install

The installer backs files up and wraps its edits in marker comments. --uninstall puts everything back.

How it works

Five steps, one key.

grim

The key bind runs qs ipc call scribe start. The focused output is captured and shown frozen.

ScribeLens

You drag a region. A sweeping line shows the read is running.

ocr.py

Crop, invert dark themes, cut into strips at blank pixel rows, one tesseract process per strip, merge the word boxes.

Select

Words are laid back over the screen where they were found. Drag to select, a toolbar floats above.

wl-copy

Copy puts the selected text on the clipboard and closes the overlay.

Install

Two minutes.

You need Hyprland, Quickshell, grim, wl-clipboard, tesseract and Python with numpy and pillow.

# Arch (Debian: apt install grim wl-clipboard tesseract-ocr python3-numpy python3-pil)
sudo pacman -S grim wl-clipboard tesseract tesseract-data-eng python-numpy python-pillow
git clone https://github.com/lunanoir21/scribe
cd scribe
./install.sh --patch      # adds the import, the host and Super+Shift+T

Without --patch the script only copies the files and prints the lines to add. Run ./install.sh --uninstall to remove everything it added.

Languages

Install them from the overlay.

After a scan, click the gear in the bottom-right corner. Tick the languages to read with. A language you do not have shows a Download button with two options. Download directly needs no password. Install with the package manager shows the command for your system, with buttons to copy it or run it in a terminal:

DistroCommand shown (needs a password)
Arch, CachyOS, Manjarosudo pacman -S --needed tesseract-data-<code>
Debian, Ubuntu, Mintsudo apt-get install -y tesseract-ocr-<code>
Fedora, RHELsudo dnf install -y tesseract-langpack-<code>
Alpinesudo apk add tesseract-ocr-data-<code>
Anything elseonly the direct download, into ~/.local/share/scribe/tessdata

scribe never asks for your password itself. The package manager command runs in your own terminal, and the direct download needs no root at all.
